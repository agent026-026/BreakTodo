BreakTodo

效率工具

产品说明

BreakTodo 帮助你将「一件大事」或复杂目标写成自然语言描述，再通过 OpenRouter 调用所选 AI 模型，生成带分组的可勾选子任务。你可以在预览后决定是否加入列表，并在日常使用中逐项完成、左滑删除任务或整组。

同类体验中，网页端的 Goblin Tools · Magic Todo（魔法待办）同样以「输入一段话 → 拆步骤」著称，是最直观的参考。BreakTodo 侧重手机上的原生清单体验：数据默认保存在本设备，并可结合你填写的「个人情况」（可选）让拆解更贴合实际约束。

功能概要

  • 自然语言描述目标，AI 生成分组与可勾选任务。
  • 使用用户自备的 OpenRouter API Key；可在设置中配置模型 ID 与个人情况文本。
  • 清单与密钥存储于本机；网络请求直连 OpenRouter（HTTPS）。
  • 支持浅色 / 深色 / 跟随系统外观。

隐私与数据

以下为 BreakTodo 在处理你的内容与调用 AI 时的数据说明。关于 OpenRouter 及各模型提供方对 API 数据的处理，须以其 隐私政策、服务条款 及各服务商公开文档为准。

我们处理哪些数据

  • 你在设备上输入或导入的待办清单、分组与勾选状态默认保存在本机，用于应用内的展示与管理。
  • 你在设置中填写的 OpenRouter API Key、所选模型 ID、以及可选的「个人情况」等说明文字保存在本机，用于组装网络请求。
  • 本应用不会在设备上收集与你身份绑定的生物特征数据；拆解功能处理的是你主动输入的文本（目标描述及上述可选上下文），而非图像或音视频。
  • 仅在你主动点击生成 / 发起拆解请求时，应用会将当次请求所需的文本内容（通常包括你的目标描述、设置中的个人情况片段、以及为调用模型所必需的参数）通过加密连接（HTTPS）直接发送至 OpenRouter；OpenRouter 会根据其路由规则将请求转发至你所选模型对应的提供方。

我们如何使用这些数据

  • 仅用于调用第三方大语言模型，将你的描述转化为分组标题与可勾选任务列表，并在应用内展示供你预览或保存。
  • 不会将你的内容用于开发者侧的广告定向、用户画像构建，或与本应用「拆解待办」功能无关的目的；开发者不运营用于中转或存储你对话内容的自有后端服务器。

是否与第三方共享、数据路径

  • 会。为实现 AI 拆解，在你发起请求时，相关文本会先由你的设备发送至 OpenRouter（openrouter.ai），再由其转发至所选模型提供方。数据路径为：你的 iPhone / iPad 设备 → OpenRouter → 所选 AI 模型服务。
  • 各环节服务商对该等数据的存储、日志与留存政策由其各自条款约束；我们不控制第三方内部日志细则，请务必查阅其官方说明。

保留期限

  • 你的设备上：清单、API Key、模型与个人情况类设置保存在应用沙盒内，直至你删除应用、清除应用数据或在设置中移除密钥。
  • OpenRouter / 模型侧：请求与响应的处理与留存遵循对应产品的现行政策，请以 OpenRouter 及各模型提供方文档为准。

你的选择与撤回

  • 你可随时在设置中移除 API Key或停止使用「生成 / 拆解」功能；未发起请求时，应用不会向 OpenRouter 传输用于拆解的文本内容。
  • 请确保你对输入内容拥有合法权利，勿提交违法、侵权或保密义务不允许外传的信息。

AI 与生成式内容声明

BreakTodo 的核心能力依赖生成式人工智能（大语言模型）将自然语言目标转换为结构化任务列表。使用本功能前，请认真阅读以下声明。

生成内容的性质

  • 应用展示的分组标题、子任务及排序建议等均由 AI 模型自动生成，并非人工撰写或事实核查结果。
  • 输出可能存在错误、遗漏、歧义、过时信息或与你的真实处境不符的情况，亦可能反映训练数据中的统计性偏见；请务必自行审阅、编辑与取舍后再纳入你的实际计划。

非专业建议

  • AI 生成的拆解步骤不构成且不能替代法律、医疗、心理、金融、安全等专业领域的建议、诊断或治疗方案。
  • 涉及人身安全、合规义务、重大疾病、心理健康危机、重大财务决定等事项，请咨询具备资质的专业人士或相关服务机构。

你的责任与合理使用

  • 你对输入内容的合法性及基于生成结果所采取的行动负责；请勿将输出用于违法、欺诈、骚扰或侵犯他人权益的行为。
  • 模型可用性、输出风格与政策以 OpenRouter 及所选模型提供方的当前服务为准；因第三方服务变更、地域限制或网络原因导致的不可用，以服务商规则为准。

系统与网络

  • 需要可访问 openrouter.ai 的网络环境，以及有效的 OpenRouter API Key。

与常见「魔法待办」类产品的关系

Magic Todo 等产品让「AI 拆任务」被广泛认知。BreakTodo 在能力上同属「描述 → 结构化步骤」，但在原生客户端、本地清单管理、OpenRouter 与模型自选等方向做了差异化，适合希望长期在手机上维护同一套清单的用户。
