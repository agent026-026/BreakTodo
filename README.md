# BreakTodo

适用于 **iOS** 的效率应用：用自然语言写下一件大事或复杂目标，通过 **OpenRouter** 调用你选择的 AI 模型，将描述拆成「分组标题 + 多条可勾选子任务」，便于按步执行、逐项打勾。API Key 与清单数据默认保存在本设备。

## 功能概要

- **AI 拆解**：输入背景与目标，生成分组预览，确认后加入列表。
- **自备 Key**：使用 **OpenRouter API Key**；可在设置中配置模型 ID、测试连接、保存个人情况（可选，会一并交给模型）。
- **本地优先**：清单与密钥存于本机；请求直连 OpenRouter（HTTPS），不经开发者自有服务器转发对话。
- **外观**：支持浅色、深色与跟随系统。
- **整理**：左滑删除清单；详情内可删除单条任务或整组；任务可勾选完成。

## 与「魔法待办」类产品的关系

网上常见的 **Goblin Tools · Magic Todo**（魔法待办）同样提供「一段话 → AI 拆步骤」，是最接近的同类能力。BreakTodo 更强调 **iOS 原生体验**、**本地清单长期维护**，以及通过 **OpenRouter 自选模型**；适合希望把拆解结果留在手机待办里、反复打开使用的场景。

## 使用前提

- 在 [openrouter.ai](https://openrouter.ai) 注册并创建 API Key，于应用设置中填写并保存。
- 网络需能访问 OpenRouter；模型 ID 须与平台支持列表一致。

## 隐私说明（摘要）

- API Key 存储在用户设备上；生成任务时，用户描述与设置中的文本通过加密连接发送至 OpenRouter 及所选模型服务。
- 详细说明以 App Store 上架的隐私政策链接为准。
